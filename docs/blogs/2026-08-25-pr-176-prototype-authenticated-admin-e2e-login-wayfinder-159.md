## Summary
- Resolves wayfinder ticket [Prototype the authenticated fixture with one working Admin login test](https://github.com/mpaulosky/Articles/issues/159), a child of map [Authenticated role-based E2E testing (Admin/Author/User via Auth0)](https://github.com/mpaulosky/Articles/issues/156).
- Proves the per-role authenticated Playwright fixture mechanism from #158 end-to-end against the real Auth0 tenant: `PlaywrightAppFixture` is now an xUnit v3 assembly fixture serving `https://localhost:7122` (HTTPS on `localhost`, matching Auth0's Allowed Callback URL exactly), `AdminAuthFixture` drives one real Universal Login and caches storage state in memory with a verified missing-creds skip, and `AdminSmokeTests` reuses that session to reach `/admin/users`.
- Fixes a real bug surfaced along the way: `RoleClaimNormalizer.cs` checked the Auth0 role claim as `https://articles/roles`, but the tenant's Post-Login Action actually emits `https://articlesite.com/roles` — this silently broke role-based authorization for every real Auth0 login, not just E2E.
- Adds `UserSecretsId` to `Web.E2E.Tests` (carried over from the prior commit on this branch) so `Auth0:E2E:{Admin,Author,User}:Username/Password` can be stored locally.
