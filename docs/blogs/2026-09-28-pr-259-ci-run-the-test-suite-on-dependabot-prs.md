## ci: Run the test suite on Dependabot PRs

- **Release tag:** `v0.1.94`
- **Source PR:** [#259](https://github.com/mpaulosky/Articles/pull/259)

### PR description

The CI workflow skipped test discovery, every test job, coverage and the report job whenever Dependabot opened the PR. GitHub counts a skipped check as passing, so the required test check went green on Dependabot bumps without a single test run. The tests now run on Dependabot PRs too.

**Needs Dependabot secrets.** Dependabot runs can't read Actions secrets. The Auth0 values the E2E tests log in with therefore also have to be set under *Settings → Secrets and variables → Dependabot*. Until they are, E2E fails on Dependabot PRs and blocks the merge. That's the intended failure mode: a bump should not merge untested.

Dependabot runs always get a read-only `GITHUB_TOKEN`, so the step that publishes the "Test Results Summary" check run and PR comment still skips there. The required test check still fails when any test did.

Validation: no new `actionlint` or `yamllint` findings in the changed file, and the pre-push hook passed.
