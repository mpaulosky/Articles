## Technical Details

### dotCover Integration

Coverage configuration in project:

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <!-- Enable coverage collection -->
    <CollectCoverage>true</CollectCoverage>
    <CoverletOutputFormat>cobertura</CoverletOutputFormat>
    <CoverletOutput>$(MSBuildProjectDirectory)/coverage/</CoverletOutput>
    
    <!-- dotCover specific -->
    <DotCoverEnabled>true</DotCoverEnabled>
    <DotCoverVersion>2024.1.0</DotCoverVersion>
  </PropertyGroup>
</Project>
```

### Coverage Commands

New test commands with coverage:

```bash
# Generate coverage report
dotnet dotcover test --dcReportType=HTML

# Generate detailed coverage with thresholds
dotnet dotcover test \
  --dcReportType=DetailedXML \
  --dcOutput=coverage/report.xml \
  --dcFilters="+:module=*;-:module=*.Tests"

# Coverage with XML output for CI
dotnet dotcover test \
  --dcReportType=XML \
  --dcOutput=coverage/coverage.xml
```

### Coverage Configuration

`.dotcover` configuration file:

```xml
<Configuration>
  <CoverageFilters>
    <!-- Include application code -->
    <IncludeFilters>
      <FilterEntry>
        <ModuleMask>Articles.*</ModuleMask>
        <ClassMask>*</ClassMask>
      </FilterEntry>
    </IncludeFilters>
    
    <!-- Exclude test projects -->
    <ExcludeFilters>
      <FilterEntry>
        <ModuleMask>*.Tests</ModuleMask>
      </FilterEntry>
      <FilterEntry>
        <ModuleMask>*.TestHelpers</ModuleMask>
      </FilterEntry>
    </ExcludeFilters>
    
    <!-- Exclude generated code -->
    <ExcludeFilters>
      <FilterEntry>
        <AttributeFilter>GeneratedCodeAttribute</AttributeFilter>
      </FilterEntry>
      <FilterEntry>
        <AttributeFilter>CompilerGeneratedAttribute</AttributeFilter>
      </FilterEntry>
    </ExcludeFilters>
  </CoverageFilters>
  
  <Thresholds>
    <StatementCoverage>80</StatementCoverage>
    <BranchCoverage>70</BranchCoverage>
    <MethodCoverage>85</MethodCoverage>
  </Thresholds>
</Configuration>
```

### Code Analysis Warning Fixes

Categories of warnings resolved:

#### 1. Nullable Reference Warnings

```csharp
// Before: CS8600 - Converting null literal
public Article? GetArticle(string id)
{
    return _articles.FirstOrDefault(a => a.Id == id);
}

// After: Proper nullable handling
public Article? GetArticle(string? id)
{
    if (id is null) return null;
    return _articles.FirstOrDefault(a => a.Id == id);
}
```

#### 2. Unused Variable Warnings

```csharp
// Before: CS0219 - Variable assigned but never used
public void ProcessArticles()
{
    var count = _articles.Count; // Never used
    foreach (var article in _articles)
    {
        // Process article
    }
}

// After: Removed unused variable
public void ProcessArticles()
{
    foreach (var article in _articles)
    {
        // Process article
    }
}
```

#### 3. Async/Await Warnings

```csharp
// Before: CS1998 - Async method lacks await
public async Task<int> GetCountAsync()
{
    return _articles.Count; // No await
}

// After: Proper async implementation
public Task<int> GetCountAsync()
{
    return Task.FromResult(_articles.Count);
}
// Or make it truly async if database involved
```

#### 4. XML Documentation Warnings

```csharp
// Before: CS1591 - Missing XML comment
public class ArticleService
{
    public Task<Article> GetAsync(string id) { }
}

// After: Proper documentation
/// <summary>
/// Provides article management services.
/// </summary>
public class ArticleService
{
    /// <summary>
    /// Gets an article by its unique identifier.
    /// </summary>
    /// <param name="id">The article identifier.</param>
    /// <returns>The article if found; otherwise, null.</returns>
    public Task<Article?> GetAsync(string id) { }
}
```

### CI/CD Integration

GitHub Actions workflow addition:

```yaml
- name: Run Tests with Coverage
  run: |
    dotnet dotcover test \
      --dcReportType=DetailedXML \
      --dcOutput=coverage/coverage.xml

- name: Check Coverage Thresholds
  run: |
    dotnet dotcover analyze coverage/coverage.xml \
      --targetArguments="--minimum-coverage=80"

- name: Upload Coverage Report
  uses: codecov/codecov-action@v3
  with:
    files: coverage/coverage.xml
    flags: unittests
    fail_ci_if_error: true
```

### Coverage Guidelines

1. **Minimum Thresholds**:
   - 80% statement coverage overall
   - 70% branch coverage overall
   - 85% for domain layer
   - 75% for application layer

2. **Exclusions**: Generated code, test helpers, migrations

3. **Review Process**: Coverage must not decrease in PRs

### Code Quality Standards
