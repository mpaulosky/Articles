## docs: Wait for main to settle before creating a worktree

### PR description

## What changed
Step 2 of `docs/CONTRIBUTING.md` now says to let `main` settle before running `git worktree add`:
- wait for the latest `squad-release.yml` run to finish
- wait until no `docs: add release blog for PR #N [skip-release]` PR is open
- then pull `main`

## Why
Twice in a row a worktree was created while the previous PR's release-blog PR (#225, then #227) was still open. `main` moved after the branch was created, and #226 needed **Update branch** on GitHub before it could merge.
