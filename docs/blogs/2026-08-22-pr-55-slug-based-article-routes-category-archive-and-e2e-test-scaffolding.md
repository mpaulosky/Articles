## Summary
- Article routes move from `/articles/{Id}` to `/articles/{Slug}`, and `Category` delete is replaced with archive/unarchive (soft delete) to match the existing article archive model.
- `ArticleAuthorizationService` gains `CanCreateArticle`, and `CanViewArticle` now lets Authors view any article (including other authors' unpublished drafts) — edit/archive permissions stay restricted to owners/Admins.
- Article and category action buttons render disabled instead of disappearing when unavailable, so users see why an action can't be taken; archiving now goes through a confirmation modal for both entities.
- Bumps Aspire packages (13.4.6 → 13.5.1 where applicable), persists the local MongoDB dev volume across AppHost restarts with fixed local-dev credentials, and speeds up incremental `npm ci` for the Tailwind build.
- Adds a Playwright-backed `Web.E2E.Tests` project with a home-page smoke test.
- Fixes the archive-confirmation modal's Cancel button, which was using the "positive" emerald button style instead of the neutral secondary style.
