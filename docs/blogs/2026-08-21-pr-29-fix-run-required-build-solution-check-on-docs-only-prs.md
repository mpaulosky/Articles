## Summary

- Fixes #26 being permanently `BLOCKED` with an empty `statusCheckRollup`: main's ruleset requires the "Build Solution" check (from `squad-ci.yml`'s `build` job), but that workflow's `pull_request` trigger had `paths-ignore: docs/**`, so it never ran at all on a docs-only PR — leaving the required check permanently missing instead of passing or failing.
- Removes `paths-ignore: docs/**` from the `pull_request` trigger only. The `push: branches: [main]` trigger keeps its `docs/**` filter since that only fires post-merge and isn't part of the merge gate.
- This affects any future docs-only PR too, including the `squad-sync-readme.yml` automation that opened #26.
