## fix(squad): Close the remaining branch-cleanup edge cases

- **Release tag:** `v0.1.102`
- **Source PR:** [#278](https://github.com/mpaulosky/Articles/pull/278)

### PR description

Fixes the four edge cases that Copilot found in `scripts/squad/cleanup-squad-branches.sh` (#247). Each fix has a test in `scripts/squad/tests/cleanup-squad-branches.test.sh`, written first and seen failing. There are now 35 tests, up from 27.

- **Closed PR, branch moved on.** A closed PR now marks a branch abandoned only when every local and remote tip is that PR's head, or an ancestor of it. A branch that was reused or pushed to after its PR closed goes through the own-commit and age checks.
- **PR opened mid-run.** The script checks again for an open PR right before each worktree removal and each local or remote delete. If GitHub can't answer, the branch is kept.
- **No `main`.** The script stops when neither `origin/main` nor `main` resolves. Before, it carried on and could mark a branch at main's tip as an orphan.
- **Worktree moved.** The script checks the captured local tip again before `git worktree remove`.

The `gh` test stub now supports an `ON_<state>_QUERY` hook. A test can use it to open a PR after the open-PR check has already run.

Once this is merged, the script still has to be rolled out to IssueManager, TicketManager, Blazor-Server, Blazor-Server-Template, atelier-store and the squad-team copy, the same way as #240.

Closes #247
