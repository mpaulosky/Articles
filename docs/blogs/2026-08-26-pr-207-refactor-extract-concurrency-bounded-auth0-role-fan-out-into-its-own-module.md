## refactor: extract concurrency-bounded Auth0 role fan-out into its own module

### PR description

## Summary
- `UserManagementHandler.Handle(GetUsersWithRolesQuery)` welded Auth0 client setup, pager draining, and the bounded `Parallel.ForEachAsync` fan-out into one closure, so testing the concurrency bound required standing up the entire Auth0 SDK object graph.
- `RolesFetchFanOut.RunAsync` pulls the bounded fan-out out as a small, generic, dependency-free module the handler calls into — testable with plain in-memory delegates instead.
- `GetRolesFetchConcurrency` is now a static, directly testable method so its config-parsing/fallback behavior isn't only covered indirectly through the handler's Auth0-mocked tests.

Follow-up architectural refactor from an `/improve-codebase-architecture` review + grilling session on the already-merged #205/#151 fix; not tied to a separate issue.
