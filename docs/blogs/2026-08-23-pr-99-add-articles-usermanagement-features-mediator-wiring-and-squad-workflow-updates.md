### PR description

## Summary
- Adds Articles list filtering/actions UI pieces (`ArticleListFilter`, `ArticleActionsCell`) and a shared `ArticleDto`/`ArticleFormModel` model set.
- Extracts Auth0 Management API client construction into a testable `IManagementApiClientFactory`, wires `UserManagementHandler` to use it instead of duplicating the token-exchange logic inline, and consolidates the `RoleDto`/`UserWithRolesDto` models into a shared `Models` namespace (matching the Articles/Categories convention).
- Wires `PipelineMediator.Send()` through the type-safe `RequestHandlerWrapper` seam instead of `dynamic` dispatch.
- Fixes two pre-existing bugs surfaced by new tests:
  - `/Account/Logout` unconditionally signed out of the Auth0 scheme even when Auth0 wasn't configured (that scheme isn't registered in that case).
  - `Auth0AuthenticationStateProvider` could add a duplicate role claim when a custom-claim role matched an existing role claim.
- Fixes `AccountEndpointsTests`' `WebApplicationFactory<Program>` content-root resolution so it doesn't depend on the process's working directory.
- Also includes prior git-workflow documentation and squad coordinator-init-mode updates already on this branch.
