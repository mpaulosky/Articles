## Summary
- Replaces the two-column Articles page with a header bar (heading, "Show My Articles Only" checkbox, "Create New Article" button) above a sortable, paginated (10/page) table of Title/Author/Category/Status/Published date with alternating row shading.

- Every visible row gets a View link to the dedicated view page; rows the current user may edit (own articles, or any article for an Admin) additionally get Publish/Unpublish, an Edit link to the dedicated edit page, and a Delete button gated behind an inline confirm/cancel step.
