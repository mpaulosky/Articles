## Parse Content into ArticleImage array on save, replace regex orphan detection

- **Release tag:** `v0.1.53`
- **Source PR:** [#142](https://github.com/mpaulosky/Articles/pull/142)

### PR description

## Summary
- `Article.Create`/`Article.Update` now derive `ArticleImages` by parsing markdown image references (`/uploads/...`) in `Content`, reusing prior upload metadata (size, mime type, uploaded timestamp) for images still referenced by the same URL.
- `ArticleFeatureHandler`'s orphan-image cleanup now diffs `ArticleImage` file names (previous vs updated) instead of re-scanning `Content` text via the old regex-based `UploadedImageReferences`, which is replaced by `ArticleImageParser`.
- Gave the `ArticleImages` `OwnsMany` mapping an explicit key (`FileName`) so EF Core can reconcile a freshly-parsed image list against previously persisted entries in a disconnected (`AsNoTracking`) update, without which saves threw `InvalidOperationException: shadow key property 'ArticleImage.Id' is unknown`.

Resolves #136 (part of the ArticleImage map, #134).
