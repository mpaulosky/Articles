## ci: Keep credentialed E2E tests off Dependabot PRs

- **Release tag:** `v0.1.95`
- **Source PR:** [#262](https://github.com/mpaulosky/Articles/pull/262)

### PR description

Follow-up to #259, which made Dependabot PRs run the test suite. Test discovery now leaves the Playwright project (`Web.E2E.Tests`) out when Dependabot opened the PR. That project logs in to Auth0 with real credentials, and an unreviewed dependency bump must not run with those. It runs on `main` once the bump merges.

No other test project reads a secret: the others use mocks, fakes and Testcontainers. So Dependabot PRs need no Dependabot secrets.

Validation: I simulated discovery with and without Dependabot; there are no new `actionlint` or `yamllint` findings in `squad-ci.yml`, and the pre-push hook passed.
