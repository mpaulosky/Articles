## What changed
Adds `GetMetadataAsync_FromLinkedWorktree_UsesWorktreeRepositoryOrigin` to `tests/Web.Tests/GitHubMetadataProviderTests.cs`. This is the follow-up to the review comment on #226, which merged before the comment could be addressed: the `File.Exists` branch of `FindGitRoot` had no test.

The test:
- creates a temporary repo whose origin is a distinct fake GitHub repo, and adds a real linked worktree to it (where `.git` is a file)
- sets the current directory to that worktree
- clears `GITHUB_REPOSITORY_URL` and `GITHUB_REPOSITORY`, both of which skip git discovery. GitHub Actions sets `GITHUB_REPOSITORY` in CI, so without this the test wouldn't reach the fixed code there. The original values are restored afterwards.
- uses a stubbed HTTP client that only answers for the fake repo, and checks that the release tag and commit come from it
