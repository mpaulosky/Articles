## Summary
- The `squad-pr-automerge.yml` workflow only enabled auto-merge for branches prefixed `squad/`, but this repo's naming convention also includes `chore/`, `hotfix/`, and `sprint/` branches — those never got auto-merge enabled.
- Widens the eligibility check to any PR from the same repo (not a fork) targeting `main`. GitHub's native auto-merge still requires all required checks to pass and no conflicts before it actually merges, so this only changes which branches are *eligible* to have auto-merge enabled — it doesn't relax any merge safety gate.
