## fix: harden Auth0 missing-config test against real env vars leaking through

- **Release tag:** `v0.1.60`
- **Source PR:** [#171](https://github.com/mpaulosky/Articles/pull/171)

### PR description

## Summary
- `AuthWiringExtensionsTests.AddAuth0Authentication_WhenConfigurationIsMissing_ThrowsInvalidOperationException` relied on an empty `AddInMemoryCollection` to mean "Auth0 config unset," but that doesn't override real process environment variables. squad-ci.yml sets `Auth0__Domain`/`ClientId`/`ClientSecret` globally, so once those secrets held real values (as of today), the "missing config" premise silently broke and the test started failing in CI (see PR #169's discussion).
- Fix: explicitly set the 3 keys to `null` in the test's own in-memory config, so it holds regardless of the process environment.
- Resolves #170.
