## ci: Lint workflows and shell scripts before push and in CI

- **Release tag:** `v0.1.98`
- **Source PR:** [#268](https://github.com/mpaulosky/Articles/pull/268)

### PR description

Brings over the workflow and shell lint the other repos now run (atelier-store, TicketManager, IssueManager, Blazor-Server), and fixes everything it found on `main`. The `squad-*` workflows are this repo's real pipelines, so they're fixed, not removed.

## New checks

- **`lint-actions.yml`** runs `actionlint`, `zizmor` (fails on medium or above) and `shellcheck`, all pinned.
- **`scripts/gate.sh`**, run by the pre-push hook, lints the changed Markdown, YAML, workflow and shell files, builds `Articles.slnx`, then runs each test project.
- **`pre-push`** checks the refs actually being pushed, and refuses a dirty working tree or a commit that isn't checked out. Branch naming rules (`squad/`, `sprint/`, `hotfix/`, `chore/`) are unchanged.

## Fixes to what the linters found

- **Every action is pinned to a commit SHA.**
- **`squad-ci.yml`:**
  - The default token is now read-only; only the report job can write.
  - Matrix values go through `env:` instead of being interpolated into scripts.
  - Checkouts no longer keep their credentials.
- **`code-metrics.yml`:**
  - `if: ${{ … }} == 'true'` was always true.
  - The dispatch reason was interpolated straight into a shell script.
  - Its push and PR triggers never fired, because a `paths:` filter with only `!` patterns matches nothing. It's now explicitly manual-only.
- **`squad-sync-readme.yml`:** its PRs could never merge. It pushed with `GITHUB_TOKEN` and a commit message carrying the skip-CI marker, so `main`'s required checks never ran. It now uses `RELEASE_PR_PAT`, drops the marker, and titles the PR `[skip-release]`. `squad-release.yml` already honours that marker.
- **`squad-promote.yml`:** `contents: write` moves from the workflow to the two jobs that push.
- **zizmor findings documented:** the `pull_request_target` triggers (`squad-pr-auto-label`, `squad-dependabot-auto-merge`), which only call the API, and the checkouts that push with their credential.
- **Every other checkout** gets `persist-credentials: false`.

## Validation

- `actionlint`, `zizmor` (online audits included), `yamllint` and `shellcheck` are clean.
- The auto-merge decision tests pass (11 of 11).
- The pre-push gate passed (build and every test project).

**Follow-up after merge:** make `actionlint`, `zizmor` and `shellcheck` required in the `main-rules` ruleset.
