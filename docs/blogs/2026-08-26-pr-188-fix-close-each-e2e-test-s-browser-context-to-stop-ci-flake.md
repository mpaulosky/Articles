## fix: close each E2E test's browser context to stop CI flake

- **Release tag:** `v0.1.67`
- **Source PR:** [#188](https://github.com/mpaulosky/Articles/pull/188)

### PR description

## Summary
`main`'s Build and Test Suite has been failing on `Tests: Web.E2E.Tests` since #186 merged: `AdminUser_CanCreateAndArchiveArticle` intermittently times out with MongoDB refusing the connection partway through the run (reproduced identically across 3 CI runs).

Root cause: `AdminAuthFixture.CreateAuthenticatedPageAsync` opens a new browser context (and its own live Blazor Server SignalR circuit) per test, but nothing ever closed them. By the third test in `AdminRoleTests`, three were accumulating for the rest of the assembly run — plausible resource pressure on a constrained CI runner that could disrupt a co-located service like MongoDB.

- Each test now closes its context once it's done, via a small `IAsyncDisposable` wrapper (`await using`).
