## fix: repair release workflow's validation dispatch loop

- **Release tag:** `v0.1.19`
- **Source PR:** [#53](https://github.com/mpaulosky/Articles/pull/53)

### PR description

## Summary
- Grant the `squad-release.yml` release job `actions: write` — it previously only had `contents: write`/`pull-requests: write`, so the new `gh workflow run` dispatch loop would 403 on every call.
- Drop `squad-ci.yml` from that dispatch loop — it only defines a `workflow_call` trigger, so it can never be dispatched via the Actions API regardless of permissions.
- Add `workflow_dispatch` to `squad-lint-markdown.yml` and `squad-lint-yaml.yml` so the release job can trigger them directly on the docs-release branch.
- Revert `permissions: { contents: read }` → `permissions: {contents: read}` in `squad-lint-yaml.yml` to satisfy the repo's yamllint `braces` rule.
