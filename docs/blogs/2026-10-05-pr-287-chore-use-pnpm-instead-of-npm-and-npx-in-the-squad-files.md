# chore: Use pnpm instead of npm and npx in the Squad files

- **Release tag:** `v0.1.107`
- **Source PR:** [#287](https://github.com/mpaulosky/Articles/pull/287)

## PR description

_Requested by **Matthew** · [project thread](https://claude.ai/code/project/chan_01M4TRjuaTvMLM1jqeNd9KNs?thread=cmsg_01M4TRjuaTvMLM1jqeNd9KNs3DS5QN3tRW9UqHQafckH16)_

### Why

Before: three Squad/Copilot files still called npm and npx: the MCP server config, the CI validation gates skill and the Tailwind migration skill.

After: they use pnpm, as the rest of the repo does. The repo-ci-baseline Apply this PR first carried (pnpm in `scripts/gate.sh` and the hooks) reached `main` through #286, so this PR now holds only these three files.

### What changed

- `.copilot/mcp-config.json`: the stdio servers start with `pnpm dlx` instead of `npx -y`.
- `.github/skills/ci-validation-gates/SKILL.md`: `pnpm publish`, `pnpm view` and `pnpm dlx semver` instead of their npm and npx forms.
- `.github/skills/tailwind-migration/SKILL.md`: `pnpm add -D` for the install, and `pnpm exec tailwindcss init` so the locally installed v3 CLI runs.

A `squad upgrade` may put the npm forms back in these files.

### Verification

- `scripts/gate.sh` passed on this branch before push (lint, Release build and all test projects).
