## Backfill migration: populate ArticleImage for existing articles

- **Release tag:** `v0.1.54`
- **Source PR:** [#144](https://github.com/mpaulosky/Articles/pull/144)

### PR description

## Summary
- Adds `ArticleImageBackfillMigration.RunAsync`, an idempotent one-time backfill that parses `Content` for every article whose `ArticleImages` array is still empty and populates it, so articles persisted before the field existed (ADR-0003) aren't left without it.
- Adds `Article.BackfillArticleImages()`, which recomputes `ArticleImages` from `Content` without otherwise touching the article (no `UpdatedAt` bump).
- Wires the migration to run once at app startup in `Program.cs` via `IDbContextFactory<ArticlesMongoDbContext>`; it's a no-op after every article has been backfilled.

## Test plan
