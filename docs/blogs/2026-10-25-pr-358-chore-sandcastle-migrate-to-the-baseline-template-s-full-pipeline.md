# chore(sandcastle): Migrate to the Baseline Template's full pipeline

- **Release tag:** `v0.1.137`
- **Source PR:** [#358](https://github.com/mpaulosky/Articles/pull/358)

## PR description

Closes #357.

Moves Articles' `.sandcastle/` from the older single-implementer pipeline onto the full one the repo-ci-baseline Template now owns (mpaulosky/dotfiles#280, mpaulosky/dotfiles#282).

- `apply.sh`: the Template's Owned files (the whole `.sandcastle/` pipeline and the other Owned drift: four workflows, `docs/PROCESS.md`, `global.json`, `check-git-hooks.sh`) and the Seed role files and `repo-config.mts`.
- Taken from the Template by hand: `Dockerfile`, `plan-prompt.md`, `review-prompt.md`. Removed the old `implement-prompt.md` and the old pipeline's `check`, `publish` and `verdict` modules.
- `test:sandcastle` is now `check:sandcastle`, in `package.json`, `check.sh`, `gate-checks.sh`, `prepare.sh` and `sandcastle-tests.yml`.
- Fixes the local run, which failed with `Cannot mount file to '.git/config'`: the new pipeline mounts it through the provider's `create()`.

`pnpm run check:sandcastle` passes (1256 tests) and the pre-push gate passed.

Not done: Articles' own `CODING_STANDARDS.md` and `check.sh` are kept as they were.
