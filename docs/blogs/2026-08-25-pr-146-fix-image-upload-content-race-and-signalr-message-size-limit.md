## fix: image-upload content race and SignalR message size limit

- **Release tag:** `v0.1.55`
- **Source PR:** [#146](https://github.com/mpaulosky/Articles/pull/146)

### PR description

## Summary
- Reorder `ContentChanged` before `UploadingChanged` in `TextEditor`'s content setter so a re-render triggered by `UploadingChanged(false)` can't clobber the just-inserted image with stale content.
- Raise SignalR's `MaximumReceiveMessageSize` to 15 MB so base64-encoded image uploads (up to ~13.3 MB for a 10 MB file, per `FileStorage`'s existing cap) don't silently disconnect the circuit mid-upload.
