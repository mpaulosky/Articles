## fix: authenticate release-notes PR creation with a PAT instead of GITHUB_TOKEN

- **Release tag:** `v0.1.27`
- **Source PR:** [#69](https://github.com/mpaulosky/Articles/pull/69)

### PR description

## Summary
- PRs opened by `squad-release.yml` were authored as `github-actions[bot]` via `GITHUB_TOKEN`, which GitHub treats as untrusted and gates every `pull_request`-triggered workflow behind a manual "Approve and run workflows" click (see PR #68).
- Point the `actions/checkout` step's `token:` (and the later `gh pr create` step's `GH_TOKEN`) at a `RELEASE_PR_PAT` secret, falling back to `GITHUB_TOKEN` if unset, so the PR is authored by a real collaborator and the approval gate no longer applies.
