### PR description

## Summary

- add the missing `scripts/squad/cleanup-squad-branches.sh` referenced by `.github/workflows/squad-branch-worktree-cleanup.yml` — the workflow would fail immediately without it
- eligibility: a branch is cleanup-eligible if it's a fast-forward ancestor of main, OR has a merged PR (needed because this repo squash-merges, so merged branches are never literal git ancestors), OR is unmerged with no open PR and older than --orphan-days
- dry-run by default; --apply performs local branch deletion, optional --delete-remote, and removes linked worktrees for eligible branches
- change the nightly schedule trigger to pass --apply/--delete-remote automatically instead of always forcing dry-run — a scheduled job whose dry-run output nobody reads was never going to clean anything up
- also changed the cron from weekly (Sundays) to nightly, same time (35 3 * * *)
