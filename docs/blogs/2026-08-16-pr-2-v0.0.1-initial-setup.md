## Overview

Welcome to the inaugural release of the Articles project! Version 0.0.1 marks the establishment of our foundation—a .NET 10-based web application designed to empower users to create, manage, and publish articles on any topic they choose.

## What's New

This initial release focuses on setting up the core infrastructure and automation that will support all future development:

### Project Setup and Validation

- **PR #2**: Comprehensive project setup review and validation
  - Established .NET 10 project structure with Aspire AppHost
  - Configured Directory.Build.props and Directory.Packages.props for centralized dependency management
  - Set up xUnit test framework with FluentAssertions
  - Implemented proper layering: Domain, Web, ServiceDefaults, and AppHost projects

### Security and Automation

- **PR #1**: Bumped CodeQL action to latest version
  - Integrated automated security scanning into CI/CD pipeline
  - Enabled vulnerability detection for C# codebase
  - Configured scheduled security scans

### Dependency Management

- Welcomed **@dependabot** as our first automated contributor
  - Configured automatic dependency update PRs
  - Set up security vulnerability alerts
  - Established foundation for keeping dependencies current

## Technical Details

The project structure follows clean architecture principles:

- **src/Domain**: Core business entities and logic
- **src/Web**: Blazor-based web application
- **src/AppHost**: Aspire orchestration for local development
- **src/ServiceDefaults**: Shared service configurations
- **tests/**: Comprehensive test coverage across all layers

All projects target .NET 10 with C# 14, nullable reference types enabled, and warnings-as-errors enforcement through Directory.Build.props.
