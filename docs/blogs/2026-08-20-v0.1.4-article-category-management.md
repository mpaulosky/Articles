## Technical Details

### CRUD Operations Architecture

The implementation follows CQRS pattern:

```csharp
// Commands
public record CreateArticleCommand(
    string Title,
    string Content,
    CategoryId CategoryId
) : IRequest<ArticleId>;

public record UpdateArticleCommand(
    ArticleId Id,
    string Title,
    string Content,
    CategoryId CategoryId
) : IRequest;

public record DeleteArticleCommand(
    ArticleId Id
) : IRequest;

// Queries
public record GetArticleByIdQuery(
    ArticleId Id
) : IRequest<ArticleDto?>;

public record GetAllArticlesQuery() 
    : IRequest<IEnumerable<ArticleDto>>;
```

### MediatR Handlers

Each operation has a dedicated handler:

```csharp
public class CreateArticleHandler 
    : IRequestHandler<CreateArticleCommand, ArticleId>
{
    private readonly IArticleRepository _repository;

    public async Task<ArticleId> Handle(
        CreateArticleCommand request, 
        CancellationToken cancellationToken)
    {
        var article = Article.Create(
            request.Title,
            request.Content,
            request.CategoryId
        );

        await _repository.AddAsync(article);
        return article.Id;
    }
}
```
