# chore: Standardize on the repo-ci-baseline Template

- **Release tag:** `v0.1.103`
- **Source PR:** [#280](https://github.com/mpaulosky/Articles/pull/280)

## PR description

### Why

Articles was one of the last two repos still on squad's workflows. This moves it onto the shared CI, release and git-hook Baseline (the `repo-ci-baseline` Template) that TicketManager, IssueTracker, atelier-store and Blazor-Server already run, so one written process ([`docs/PROCESS.md`](docs/PROCESS.md)) covers every repo.

### What changed

The commits follow the Standardize steps, so each one can be reviewed on its own:

1. **Lasting squad decisions moved to `docs/decisions.md`:** the Tailwind component styles and the separate Auth0 Management API configuration, plus an entry recording the removal. The rest of the squad log (release rules, ceremony) was dropped.
2. **Squad removed:**
   - `.squad/`
   - 14 `squad-*` workflows and `sync-squad-labels.yml`
   - `scripts/squad/`, including the branch-cleanup script: GitHub already deletes head branches on merge, and it only targeted `squad/` and `sprint/` names
   - the coordinator agent, 24 squad skills and the `squad_state` MCP server
   - squad references in the README, `SECURITY.md`, two prompts and the solution-scaffolder skill
3. **`chore: apply repo-ci-baseline Template`:** exactly the output of `apply.sh` (33 Owned files added, 17 overwritten, 7 Seed files written).
4. **Clean build under `-warnaserror`**, which the Baseline's gate and CI use:
   - fixes CA2007 and CA1848 in the image backfill service
   - suppresses CA1002, CA1054 and CA1056 on the Mongo-mapped image members, whose stored shape is fixed by ADR 0003
   - suppresses ASPIRE010 in the AppHost
   - test-project analyzer suppressions move to `tests/.editorconfig`, and the `app.css` and `uploads/` ignores move to `src/Web/.gitignore`, since the root files are Owned now
   - `.github/ci/prepare.sh` enables pnpm through corepack for the Tailwind build
5. **Dependabot:** `chore(deps)` commit prefixes and a Testcontainers group, from the Seed.
6. **Markdown lint back on.** `.markdownlint.json` held `{"default": false}`, which switched every rule off. It's deleted, along with the duplicate commit rules in `.copilot-commit-message-instructions.md`, and the ~380 findings are fixed.
7. **Docs:**
   - CONTRIBUTING and AGENTS.md point at `PROCESS.md`.
   - The README and `docs/index.html` get the markers the release workflow fills, filled once by `release_post.py`. The page's script now only loads the version badge, so ADR 0001 is marked superseded.
   - The 15 posts named by version (`2026-08-16-v0.0.1-...`) get their PR number, so the first release run doesn't write them again.

8. **E2E test users:** the fixtures read `Auth0:Admin:*`, `Auth0:Author:*` and `Auth0:User:*`, the names the `TEST_ENV` secret and the local user secrets use, instead of `Auth0:E2E:*`. The old `squad-ci.yml` mapped the secrets to the `E2E` names itself; without this change, 9 of the 10 E2E tests skipped under the new `ci.yml`.

The old "Cache build artifacts" step is gone with the old `ci.yml`.
