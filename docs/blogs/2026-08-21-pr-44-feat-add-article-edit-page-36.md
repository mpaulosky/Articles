## Summary
- Adds `ArticleEditPage.razor` at `/articles/{Id}/edit`, reusing the shared `ArticleForm` component from #33.
- Loads the target Article and Categories, pre-fills the form (Title, Content, Category) from the Article's current values.
- Gates access via `ArticleAuthorizationService.CanEditArticle` (owning Author or Admin) — anyone else sees a permission-denied message and the form/article content is never rendered.
- Saves through the existing `UpdateArticleCommand`/handler; on success redirects to the Article's view page (`/articles/{Id}`) so the updated values are immediately visible there.
- On a failed save, the error is shown alongside the still-populated form so in-progress edits aren't lost.

Closes #36
