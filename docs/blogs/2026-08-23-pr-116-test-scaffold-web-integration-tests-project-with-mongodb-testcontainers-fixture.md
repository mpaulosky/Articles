## Summary
- Adds a new `Web.Integration.Tests` project (xUnit v3, FluentAssertions, `Testcontainers.MongoDb`) that exercises real MongoDB instead of the EF Core InMemory provider `Web.Tests` currently uses for repository tests.
- `MongoContainerFixture` starts one MongoDB container (pinned to `8.2.12`, matching AppHost's local-dev pin) once per assembly; each test class gets its own database name inside it, so parallel xUnit collections stay isolated without per-class container overhead.

- No CI workflow changes needed — `squad-ci.yml`'s `discover-tests` job auto-discovers projects under `tests/**`, and ubuntu-latest runners already have Docker.
