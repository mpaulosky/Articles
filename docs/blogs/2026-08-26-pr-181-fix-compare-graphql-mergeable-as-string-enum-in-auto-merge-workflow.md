## fix: compare GraphQL mergeable as string enum in auto-merge workflow

- **Release tag:** `v0.1.64`
- **Source PR:** [#181](https://github.com/mpaulosky/Articles/pull/181)

### PR description

## Summary
- `squad-pr-automerge.yml` compared `pullRequest.mergeable` to boolean `true`, but GitHub's GraphQL API returns it as a `MergeableState` enum string (`"MERGEABLE"`/`"CONFLICTING"`/`"UNKNOWN"`). The check silently never matched, so `enablePullRequestAutoMerge` was never called even on fully green, mergeable PRs.
- Surfaced on PR #178, where all checks passed and `mergeStateStatus` was `CLEAN`, but auto-merge never engaged; the workflow's own log showed `Skipping PR #178: mergeable=MERGEABLE mergeStateStatus=CLEAN` because `"MERGEABLE" === true` is false.
- Fixes the comparison to `currentPr.mergeable === "MERGEABLE"`.
